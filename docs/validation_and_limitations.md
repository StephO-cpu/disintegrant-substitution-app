# Validation and Limitations

## Data Sources
Because I do not have access to live laboratory equipment or proprietary manufacturing records, the data and parameters used in this project are derived from:
1. Published peer-reviewed literature (characterization studies, dissolution profiles).
2. Standard pharmacopeial limits (USP/BP).
3. Open-source GxP and ALCOA+ guidance documents (WHO, PIC/S, FDA).

## Scope of Validation
This project demonstrates the **software architecture and logic**. 
- It is NOT a validated GxP system (it has not undergone IQ/OQ/PQ).
- It is intended as a portfolio piece to demonstrate computational pharmaceutics skills.

## Human-in-the-Loop
This tool is designed to assist professionals (QA managers, formulation scientists), not replace them. Human review and final sign-off are required for any real-world application.
